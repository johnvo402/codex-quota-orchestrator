Quota policy

Hard/soft pause thresholds apply to both quota windows. Resume then requires each available window to meet its own resume threshold. A resume threshold below the soft threshold effectively resumes only after that window is above soft. Defaults: 5h 20%, weekly 5%.

Server

Only loopback addresses are accepted: 127.0.0.1, localhost, or ::1. This keeps the unauthenticated local control API off the LAN.
